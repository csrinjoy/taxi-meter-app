GitHub Hosting & Deployment Guide

How to host this app on GitHub Pages for free:

  1. Create a new public repository on GitHub.com (e.g., taximeter-app).
  2. Save this code into a file named index.html in your repository.
  3. Go to your repository settings -> Pages.
  4. Under Build and deployment, select Deploy from a branch and choose your main branch (e.g., main) and root folder / (root).
  5. Click Save! Your taxi app will be live globally in under a minute with zero API keys required.
